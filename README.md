## Project Overview :rocket:
Maze was created as a final project for the **"Programming AI"** course.  
It is a **single-player, third-person 3D maze survival prototype**, developed in **Unreal Engine 5** using BLueprints.
THe game focuses on distance-driven combat logic and AI state switching.

The main goal of the project was to implement and compare two different AI approaches:
- Blueprint-based AI
- Behaviour Tree-based AI

---

## Features :fire:
- Maze navigation gameplay
- Different AI systems - enemies
- Combat system based on the distance of the enemy from the player
- State-based AI switching
